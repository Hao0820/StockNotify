# StockNotify — 台股隱藏飆股雙軌雷達 (Supabase + Vercel)

這是一套運行在 **Supabase (PostgreSQL + pg_cron + Edge Functions)** 與 **Vercel 前端看板** 的全自動化台股選股與 Discord 推播系統。

## ⏰ 自動化排程時間
- **每週一至週五 早上 08:00 (台灣時間 `UTC+8`, Cron: `0 0 * * 1-5`)**：自動掃描全市場上市 (TWSE) 與上櫃 (TPEx) 普通股，精選 **Top 10** 寫入 Supabase 並推播至 Discord，同時同步更新至網頁看板。

---

## 🎯 滿分 100 分雙軌選股模型

### 1. 主力 5日/10日 籌碼集中度與法人大戶（最高 35 分）
- **5日 / 10日主力籌碼集中度（最高 15 分）**：對齊《籌碼K線》公式 `(近 N 日買方 Top 15 券商分點合計 - 賣方 Top 15 券商分點合計) ÷ 區間總成交量`。
- **三大法人 5日 / 10日 買超與連買（最高 12 分）**：外資、投信波段累積買超與連買天數。
- **TDCC 集保 400 張以上大戶持股比例（最高 8 分）**：集保中心最新一期 400 張以上大戶（級距 12~15）持股百分比。

### 2. 日/週/月 多週期 12EMA 與布林通道 `(21, 2.1)` 支撐型態（最高 35 分）
- **多週期支撐命中（最高 25 分）**：
  - **日線（誤差 ≤ `1%`）**：日 12EMA、日布林中軌(21, 2.1)、日布林下軌(21, 2.1)
  - **週線（誤差 ≤ `3%`）**：週 12EMA、週布林中軌(21, 2.1)、週布林下軌(21, 2.1)
  - **月線（誤差 ≤ `5%`）**：月 12EMA、月布林中軌(21, 2.1)、月布林下軌(21, 2.1)
- **布林通道壓縮 Squeeze 與量能配合（最高 10 分）**：布林帶寬收斂（`≤ 15%`）或帶量突破 / 量縮回測支撐。

### 3. 技術動能指標（最高 30 分）
- **KD (9, 3, 3)（最高 10 分）**：黃金交叉或即將金叉。
- **RSI (6, 12)（最高 10 分）**：短天期 RSI6 向上穿越或逼近長天期 RSI12。
- **MACD (12, 26, 9)（最高 10 分）**：柱狀體 (OSC) 翻紅、紅柱持續放大或綠柱明顯收斂。

## 🌐 部署至 Vercel 網頁看板

本專案根目錄已內建零依賴、響應式的現代深色看盤網頁 [`index.html`](./index.html) 與 [`vercel.json`](./vercel.json)，會直接透過 Supabase REST API 即時讀取每日推薦的 **Top 10** 標的，並支援：
- 依日期與場次切換歷史推薦紀錄
- 篩選 `全部` / `🔥 支撐起漲共振` / `💎 隱藏潛伏回測`
- 點擊 **「立即重新掃描」** 觸發雲端即時重算並發送 Discord 通知

### 部署方式 A：透過 GitHub 連結 Vercel（推薦）
1. 將 `C:\Users\Wesley\Documents\Projects\StockNotify` 推送至您的 GitHub 儲存庫。
2. 登入 [Vercel](https://vercel.com/) → 點選 **Add New...** → **Project**。
3. 匯入該 GitHub 儲存庫，Framework Preset 保持 `Other`，直接點選 **Deploy** 即可完成部署！

### 部署方式 B：使用 Vercel CLI 直接部署
若電腦已安裝 Node.js，可在專案目錄下執行：
```powershell
cd C:\Users\Wesley\Documents\Projects\StockNotify
npx vercel --prod
```
